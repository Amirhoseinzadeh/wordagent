# واژه‌یار (WordAgent) 🗣️📚

اپلیکیشن اندروید/iOS/دسکتاپ/وب برای **یادگیری واژگان انگلیسی توسط فارسی‌زبان‌ها**؛
الگو گرفته از ساختار آموزشی و تجربه‌ی کاربری اپ‌هایی مثل WordUp، اما کاملاً
**فارسی‌سازی‌شده** (رابط، محتوا، تاریخ شمسی، اعداد فارسی) و متناسب با فرهنگ
کاربر ایرانی.

> وضعیت: نسخه‌ی `1.0.0` — اپ کامل و آفلاین کار می‌کند؛ محتوای ۸۳۸ واژه‌ای
> درون بسته‌ی اپ است و لایه‌ی به‌روزرسانی آنلاین محتوا آماده است.
> اتصال به بک‌اند/Supabase طبق برنامه، در مرحله‌ی آخر انجام می‌شود.
>
> **کنترل کیفیت:** `flutter analyze` بدون هیچ ایرادی، 308 تست در ۱۹ فایل
> (واحد، داده، ویجت) همه سبز، و `flutter build web --release` موفق.
> همین سه مرحله در GitHub Actions اجرا می‌شود و خروجی هر اجرا به‌صورت
> خودکار در یک کامنت روی همان کامیت منتشر می‌شود.

## ✨ قابلیت‌های کلیدی

| حوزه | چه چیزی پیاده شده است |
| --- | --- |
| تعیین سطح | آزمون تطبیقی ۱۲–۱۸ سؤالی بر پایه‌ی مدل Elo/Rasch؛ سطح CEFR کاربر از شواهد پاسخ‌ها برآورد می‌شود |
| تکرار فاصله‌دار | موتور SRS توسعه‌یافته‌ی SM-2 با مراحل کوتاه‌مدت، ضریب آسانی پویا (۱٫۳–۲٫۸)، لرزش قطعی ±۵٪ و سقف یک‌ساله |
| تشخیص ضعف | موتور تحلیل خطا با امتیازدهی به لغزش/نرخ خطا/نزدیکی زمانی و تفکیک بر پایه‌ی نقش دستوری و موضوع |
| تمرین‌ها | کارت هوشمند، چهارگزینه‌ای معنی/واژه، جای خالی، نوشتن معنی، نوشتن واژه، شنیداری، جمله‌سازی، کالوکیشن، مترادف، متضاد |
| محتوای هر واژه | معنی دقیق فارسی، توضیح فارسی، IPA + تلفظ صوتی، مثال انگلیسی + ترجمه، مثال گفت‌وگویی، دیالوگ فیلم/سریال، هم‌معنی/متضاد، کالوکیشن، شکل‌های صرفی خودکار (گذشته/اسم مفعول/جمع/برترین…)، برچسب موضوعی، ایموجی، یادداشت فرهنگی و کارت تصویر |
| انگیزش | XP و ۶۰ سطح با لقب فارسی، کمبو، زنجیره‌ی روزانه با «سپر زنجیره»، چالش روزانه، ۳۵ دستاورد، نمودار پیشرفت ۳۰ روزه |
| دستیار آموزشی | موتور محلی «مدرس» برای توضیح ساده‌تر، مثال تازه در سطح کاربر، تشخیص اشتباه پرتکرار و پیشنهاد واژه‌های مرتبط |
| اشتراک | مدل رایگان + ماهانه/سالانه/همیشگی، دروازه‌ی پرداخت ماک (آماده‌ی اتصال به کافه‌بازار/مایکت/StoreKit)، تبلیغ غیرمزاحم فقط برای کاربر رایگان |
| کشف محتوا | جست‌وجوی هوشمند (واژه، شکل‌های صرفی، معنی فارسی، هم‌معنی و موضوع)، مرور بر اساس سطح CEFR و ۲۱ موضوع، بسته‌های موضوعی، نشان‌گذاری، پیشنهاد واژه بر اساس هدف یادگیری |
| تجربه‌ی کاربری | تم روشن و تیره، انیمیشن‌های نرم، RTL کامل، فونت وزیرمتن، صفحات مرگ/خالی/بارگذاری استاندارد |

## 🚀 شروع سریع

```bash
flutter pub get
flutter run                 # اندروید، iOS، دسکتاپ یا وب
flutter test                # اجرای مجموعه‌ی تست
flutter analyze             # تحلیل ایستا
```

همین چهار مرحله به‌صورت خودکار در GitHub Actions نیز اجرا می‌شود
([`.github/workflows/ci.yml`](.github/workflows/ci.yml)).

بررسی سریع محتوا (بدون نیاز به Flutter):

```bash
python3 tools/build_content.py     # بازسازی assets/content/*.json از tools/content/*.txt
node tools/dev/dartcheck.mjs .     # تحلیل ایستای سبک برای محیط‌های بدون SDK
```

## 🗂️ ساختار پروژه

```
lib/
├── core/            # زیرساخت: تم، ذخیره‌سازی، سرویس‌ها، DI، مسیرها، ابزارهای فارسی
├── domain/          # موجودیت‌ها + موتورهای خالص (SRS، XP، زنجیره، ضعف، دستاورد، مسیر یادگیری)
├── data/            # منابع محتوا، نگاشت‌گرهای JSON و پیاده‌سازی مخزن‌ها
├── features/        # صفحه‌های محصول (خانه، مرور، تمرین، چالش، کاوش، پیشرفت، پروفایل، …)
├── widgets/         # ویجت‌های مشترک و قابل‌استفاده‌ی مجدد
└── l10n/            # همه‌ی متن‌های فارسی رابط + برچسب‌های وابسته به داده
assets/content/      # محتوای تولیدشده (واژه‌ها، بسته‌ها، مانیفست نسخه)
tools/               # خط تولید محتوا و ابزار تحلیل ایستا
docs/                # مستندات معماری، محتوا، تست و نقشه‌ی راه
test/                # تست‌های واحد، داده و ویجت
```

معماری کامل‌تر: [`docs/architecture.md`](docs/architecture.md)

## 🧠 چطور کار می‌کند (خلاصه)

1. کاربر در **تعیین سطح** شرکت می‌کند یا از پیش سطح خود را انتخاب می‌کند.
2. **موتور مسیر یادگیری** هر بار سه برنامه می‌سازد: مرور سررسیده‌ها، واژه‌های تازه‌ی هم‌سطح، تقویت نقاط ضعف.
3. هر پاسخ، هم **زمان‌بندی مرور** را به‌روز می‌کند (SRS) و هم **امتیاز/زنجیره/دستاورد** می‌سازد.
4. **موتور ضعف** از الگوی خطاها، حوزه‌های دشوار و واژه‌های سخت‌آموز را پیدا می‌کند و تمرین هدفمند پیشنهاد می‌دهد.
5. محتوا درون بسته است؛ اگر نسخه‌ی تازه‌ای از سرور بیاید، همان لایه بدون تغییر در بقیه‌ی اپ جایگزین می‌شود.
