# خط تولید محتوا

محتوای آموزشی از فایل‌های متنی ساده تولید می‌شود تا:
پیشرفت هر واژه در Git **قابل بازبینی و diff** باشد، محتوا **بدون کد زدن**
گسترش پیدا کند، و بسته‌ی نهایی برای اپ **کم‌حجم و آماده‌ی مصرف** باشد.

```
tools/content/*.txt  ──(python3 tools/build_content.py)──►  assets/content/*.json
```

## ورودی‌ها

### ۱) `words_a1.txt` … `words_c2.txt`

هر خط یک واژه؛ فیلدها با `||` جدا می‌شوند:

```
term||pos||level||fa(؛)||def||ex_en||ex_fa||conv_en||conv_fa||col||syn||ant||note||emoji||topics||forms(label:value)||mnemonic||premium
```

| # | فیلد | توضیح |
| --- | --- | --- |
| ۱ | `term` | واژه‌ی انگلیسی |
| ۲ | `pos` | کد نقش دستوری: `n` `v` `adj` `adv` `prep` `pron` `conj` `det` `intj` `num` `phr` `phrv` `idiom` |
| ۳ | `level` | سطح CEFR (با نام فایل یکی است) |
| ۴ | `fa` | معنی‌های فارسی جدا‌شده با `؛` (سرراست و روزمره) |
| ۵ | `def` | توضیح فارسی ساده (یک جمله، برای کاربر ایرانی) |
| ۶ | `ex_en` | مثال انگلیسی |
| ۷ | `ex_fa` | ترجمه‌ی روان مثال |
| ۸ | `conv_en` | مثال گفت‌وگویی/روزمره |
| ۹ | `conv_fa` | ترجمه‌ی مثال گفت‌وگویی |
| ۱۰ | `col` | کالوکیشن‌ها (با `؛`) |
| ۱۱ | `syn` | هم‌معنی‌ها |
| ۱۲ | `ant` | متضادها |
| ۱۳ | `note` | نکته‌ی فرهنگی/کاربردی فارسی |
| ۱۴ | `emoji` | ایموجی واژه (برای کارت‌ها) |
| ۱۵ | `topics` | موضوع‌ها (با `؛`) — برای هم‌راستایی با هدف یادگیری |
| ۱۶ | `forms` | شکل‌های واژه: `قید:resiliently؛صفت:resilient` |
| ۱۷ | `mnemonic` | یادیار فارسی |
| ۱۸ | `premium` | اگر `1`/`premium`/`vip` باشد، واژه‌ی ویژه می‌شود |

### ۲) `media_lines.txt`

دیالوگ‌های ماندگار فیلم و سریال:

```
term||جمله||ترجمه||عنوان اثر||سال||گوینده(اختیاری)
```

اگر واژه در فایل‌های واژگان نباشد، خط **بی‌صدا رد می‌شود** (هشدار می‌گیرید).

### ۳) `packs.txt`

بسته‌های موضوعی:

```
id||title||desc||emoji||words(؛)||level||premium(1)
```

واژه‌های هر بسته باید دقیقاً با `term` واژه‌های موجود یکی باشند؛ در غیر این
صورت بیلدر گزارش خطا می‌دهد.

### ۴) `topics.txt`

برچسب موضوعی هر واژه — ستون فقرات شخصی‌سازی:

```
term||برچسب‌ها(؛)
time||time؛daily
academic||academic؛science
```

بیلدر این فایل را **اعتبارسنجی سخت** می‌کند: واژه‌ی ناشناخته، برچسب ناشناخته،
خط تکراری یا واژه‌ی بدون برچسب باعث می‌شود بیلد با کد خروجی `1` تمام شود.
مجموعه‌ی برچسب‌های مجاز (که اپ هم فارسی‌شان را می‌شناسد، در
`TopicLabels` در `lib/l10n/labels.dart`):

```
daily people home food travel work business money study academic
science tech media sports health body feelings nature society time thought
```

این برچسب‌ها سه جا اثر می‌گذارند:

1. **پیشنهاد واژه‌ی تازه:** واژه‌های هم‌موضوع با هدف کاربر امتیاز بیشتری می‌گیرند
   (`SessionBuilder`).
2. **تحلیل ضعف:** دقت کاربر به تفکیک موضوع حساب می‌شود و کارت «نقاط ضعف» صفحه‌ی
   پیشرفت، ضعیف‌ترین موضوع‌ها را نشان می‌دهد.
3. **ارتباط واژه‌ها:** دستیار آموزشی برای پیشنهاد واژه‌ی مرتبط از اشتراک موضوعی
   استفاده می‌کند.

### ۵) `extra_collocations.txt`

تکمیل کالوکیشن‌های واژه‌های پرکاربرد:

```
term||+ترکیب تازه؛ترکیب تازه‌ی دیگر     → افزودن به ترکیب‌های موجود
term||=ترکیب؛ترکیب                      → جای‌گزینی ترکیب‌های موجود
```

- در حالت `+` اگر ترکیب تکراری باشد، دوباره اضافه نمی‌شود.
- در حالت `=` ترکیب‌های قبلی کنار می‌روند (برای اصلاح محتوای ضعیف).
- واژه‌ی ناشناخته یا خط تکراری ⟶ بیلد با کد `1` تمام می‌شود.
- **قاعده‌ی مهم:** هر واژه باید دست‌کم یک ترکیب داشته باشد که خودِ واژه در آن
  آمده باشد؛ چون تمرین «کالوکیشن» همان ترکیب را به‌عنوان پاسخ درست نشان
  می‌دهد و گزینه‌های دیگر از ترکیب‌های واژه‌های دیگر می‌آیند. بیلدر اگر ترکیب
  اول این شرط را نداشته باشد هشدار می‌دهد و
  `test/data/content_depth_test.dart` آن را قفل کرده است.

## خروجی‌ها (`assets/content/`)

| فایل | محتوا |
| --- | --- |
| `words_<level>.json` | `{level, count, words:[…]}` — هر واژه با کلیدهای کوتاه: `id term pos level ipa rank diff fa def ex col syn ant note emoji topics forms mnemonic premium image` |
| `packs.json` | `{packs:[{id,title,desc,emoji,words,level,seed,premium}]}` |
| `manifest.json` | نسخه، شمار واژه‌ها به تفکیک سطح، شمار دیالوگ‌ها، شمار بسته‌ها، توزیع نقش دستوری، شمار واژه‌های دارای شکل صرفی (`withForms`)، شمار واژه‌های دارای دو کالوکیشن یا بیشتر (`withCollocations`) و توزیع برچسب‌های موضوعی (`topicTags`) |

شناسه‌ها `{level}{3 رقم}` هستند (مثلاً `b1_042`) و در همه‌ی فایل‌ها یکتا می‌مانند.

## تصاویر واژه‌ها (`assets/images/`)

تصویر هر واژه **بخشی از فایل متنی نیست**؛ بیلدر هنگام ساخت بسته، پوشه‌ی
`assets/images/` را نگاه می‌کند و اگر فایلی هم‌نام شناسه‌ی واژه باشد، ارجاع آن
را در `image` همان واژه می‌گذارد:

```
assets/images/b1_042.webp  →  "image": "assets/images/b1_042.webp"
```

- پسوندهای پذیرفته‌شده: `.webp` (پیشنهادشده)، `.png`، `.jpg`، `.jpeg`.
- اندازه‌ی پیشنهادی: کمتر از ۲۰۰ کیلوبایت، نسبت ۴:۳ یا ۱۶:۹.
- تصویر بزرگ‌تر از ۲ مگابایت هنگام ساخت هشدار می‌دهد.
- نبودن تصویر خطا نیست؛ رابط کاربری در آن حالت کارت تزئینی با حرف نخست
  واژه نشان می‌دهد. تصاویر آنلاین (فاز بک‌اند) از کلید `image_url` می‌آیند و
  اولویت پایین‌تری از تصویر محلی دارند.

## کارهایی که بیلدر خودکار انجام می‌دهد

- **تلفظ IPA:** تبدیل خروجی ARPAbet فرهنگ `cmudict` به الفبای آوانگاری بین‌المللی.
- **رتبه‌ی کاربرد:** محاسبه از پیکره‌ی `wordfreq` (۵۰٬۰۰۰ واژه‌ی اول) برای
  مرتب‌سازی هوشمند صف یادگیری.
- **درجه‌ی دشواری (۱..۵):** از سطح CEFR، رتبه‌ی کاربرد و املای واژه.
  (`a1/a2 → ۱`، `b1 → ۲`، `b2 → ۳`، `c1 → ۴`، `c2 → ۵` با اصلاح‌های جزئی)
- **الگوهای صرفی نمونه‌ها:** `term_forms()` شکل‌های منظم و بی‌قاعده‌ی واژه را
  می‌سازد تا در مثال‌ها و تمرین «جای خالی» درست تشخیص داده شود.
- **شکل‌های صرفی واژه (`forms`):** برای هر فعل (`گذشته`، `اسم مفعول`،
  `حال استمراری`، `سوم‌شخص مفرد`)، هر اسم قابل‌شمارش (`جمع`) و هر صفت
  درجه‌پذیر (`برتر`، `برترین`) خودکار ساخته می‌شود:
  * جدول فعل‌های بی‌قاعده (۳۸ فعل)، جمع‌های بی‌قاعده (`child → children`) و
    صفت‌های بی‌قاعده (`good → better, best`) دستی نگه‌داری می‌شوند؛
  * دوبرابر شدن حرف آخر برای فعل‌های تک‌سیلابی و فهرست کوچکی از فعل‌های
    تکیه‌آخر (`stop → stopped`, `occur → occurred`, `forget → forgetting`)؛
  * املای آمریکایی (`travel → traveled`, `focus → focusing`)؛
  * اسم‌های غیرقابل‌شمارش (`water`, `money`, `people`, `series`) و صفت‌های
    درجه‌ناپذیر (`same`, `unique`, `sole`) شکل نمی‌گیرند.
  همین شکل‌ها در صفحه‌ی جزئیات واژه نمایش داده می‌شوند و در تمرین‌های
  نوشتاری هم پاسخ پذیرفته‌شده به حساب می‌آیند.
- **تصاویر:** ارجاع خودکار تصویر از پوشه‌ی `assets/images/` (بر پایه‌ی شناسه‌ی واژه).
- **اعتبارسنجی:** یکتا بودن شناسه، کد نقش دستوری/سطح، وجود خودِ واژه در مثال‌ها،
  هم‌خوانی واژه‌های بسته‌ها با واژگان، و رد شدن اعداد/کاراکترهای بیگانه.

## اجرا

```bash
python3 tools/build_content.py        # فقط پایتون استاندارد + cmudict/wordfreq اختیاری
```

اجرای کامل (با تلفظ و رتبه‌ی تازه):

```bash
python3 -m venv /tmp/tools && /tmp/tools/bin/pip install cmudict wordfreq
/tmp/tools/bin/python tools/build_content.py
```

اگر `cmudict` یا `wordfreq` نصب نباشند، بیلدر **محتوای فعلی را خراب نمی‌کند**:
تلفظ و رتبه‌ی کاربرد از بسته‌ی موجود (`assets/content/`) برداشته می‌شود و بقیه‌ی
فیلدها از فایل‌های متنی ساخته می‌شوند. پس می‌شود بدون اینترنت هم فقط برچسب
موضوعی یا شکل‌های صرفی را ساخت. چهار واژه‌ی چندبخشی (`learn from`,
`remember to`, `improve on`, `free time`) تلفظ دستی دارند چون `cmudict` فقط
واژه‌ی تک‌کلمه‌ای را می‌شناسد.

خروجی نمونه:

```
  words_a1.txt → 117 واژه
  …
  ✓ words_b1.json — 192 واژه (…KB)
  ✓ packs.json — 23 بسته
  ✓ manifest.json
```

## افزودن واژه‌ی تازه (دستور کار)

1. واژه را به فایل سطح مناسب اضافه کنید (خط تازه در `words_<level>.txt`).
2. یک خط تازه در `topics.txt` برای همان واژه بگذارید (دست‌کم یک برچسب).
3. اگر لازم است، در `media_lines.txt` دیالوگ و در `packs.txt` بسته‌ی مرتبط
   را به‌روز کنید. شکل‌های صرفی خودکار ساخته می‌شوند؛ اگر فعل/اسم بی‌قاعده‌ی
   تازه‌ای اضافه کردید، جدول‌های بالای `build_content.py` را کامل کنید.
4. اگر واژه کالوکیشن بیشتری لازم دارد، در `extra_collocations.txt` اضافه کنید.
5. `python3 tools/build_content.py` را اجرا کنید و هشدارها را بررسی کنید.
   اگر بیلد با کد `1` تمام شد، ایراد برچسب‌های موضوعی/کالوکیشن را برطرف کنید.
6. `node tools/dev/dartcheck.mjs .` و `flutter test` را اجرا کنید؛ تست‌های
   `test/data/content_source_test.dart` کیفیت محتوا (معنی فارسی، ترجمه‌ی مثال‌ها،
   اعتبار بسته‌ها) و `test/data/content_depth_test.dart` برچسب موضوعی، شکل‌های
   صرفی و تلفظ را می‌سنجند.

> نسخه‌ی محتوای تولیدشده در `manifest.json` ثبت می‌شود؛ افزایش آن به‌معنی
> بسته‌ی تازه برای کاربر است. به‌روزرسانی نهایی روی دستگاه از مسیر
> `ContentSource` (کلید `content_override_v1`) انجام می‌شود.
