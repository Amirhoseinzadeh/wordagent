# خط تولید محتوا

محتوای آموزشی از فایل‌های متنی ساده تولید می‌شود تا:
پیشرفت هر واژه در Git **قابل بازبینی و diff** باشد، محتوا **بدون کد زدن**
گسترش پیدا کند، و بسته‌ی نهایی برای اپ **کم‌حجم و آماده‌ی مصرف** باشد.

```
tools/content/*.txt  ──(python3 tools/build_content.py)──►  assets/content/*.json
```

## ورودی‌ها

### ۱) `words_a1.txt` … `words_c2.txt`

هر خط یک واژه؛ فیلدها با `||` جدا می‌شوند:

```
term||pos||level||fa(؛)||def||ex_en||ex_fa||conv_en||conv_fa||col||syn||ant||note||emoji||topics||forms(label:value)||mnemonic||premium
```

| # | فیلد | توضیح |
| --- | --- | --- |
| ۱ | `term` | واژه‌ی انگلیسی |
| ۲ | `pos` | کد نقش دستوری: `n` `v` `adj` `adv` `prep` `pron` `conj` `det` `intj` `num` `phr` `phrv` `idiom` |
| ۳ | `level` | سطح CEFR (با نام فایل یکی است) |
| ۴ | `fa` | معنی‌های فارسی جدا‌شده با `؛` (سرراست و روزمره) |
| ۵ | `def` | توضیح فارسی ساده (یک جمله، برای کاربر ایرانی) |
| ۶ | `ex_en` | مثال انگلیسی |
| ۷ | `ex_fa` | ترجمه‌ی روان مثال |
| ۸ | `conv_en` | مثال گفت‌وگویی/روزمره |
| ۹ | `conv_fa` | ترجمه‌ی مثال گفت‌وگویی |
| ۱۰ | `col` | کالوکیشن‌ها (با `؛`) |
| ۱۱ | `syn` | هم‌معنی‌ها |
| ۱۲ | `ant` | متضادها |
| ۱۳ | `note` | نکته‌ی فرهنگی/کاربردی فارسی |
| ۱۴ | `emoji` | ایموجی واژه (برای کارت‌ها) |
| ۱۵ | `topics` | موضوع‌ها (با `؛`) — برای هم‌راستایی با هدف یادگیری |
| ۱۶ | `forms` | شکل‌های واژه: `قید:resiliently؛صفت:resilient` |
| ۱۷ | `mnemonic` | یادیار فارسی |
| ۱۸ | `premium` | اگر `1`/`premium`/`vip` باشد، واژه‌ی ویژه می‌شود |

### ۲) `media_lines.txt`

دیالوگ‌های ماندگار فیلم و سریال:

```
term||جمله||ترجمه||عنوان اثر||سال||گوینده(اختیاری)
```

اگر واژه در فایل‌های واژگان نباشد، خط **بی‌صدا رد می‌شود** (هشدار می‌گیرید).

### ۳) `packs.txt`

بسته‌های موضوعی:

```
id||title||desc||emoji||words(؛)||level||premium(1)
```

واژه‌های هر بسته باید دقیقاً با `term` واژه‌های موجود یکی باشند؛ در غیر این
صورت بیلدر گزارش خطا می‌دهد.

## خروجی‌ها (`assets/content/`)

| فایل | محتوا |
| --- | --- |
| `words_<level>.json` | `{level, count, words:[…]}` — هر واژه با کلیدهای کوتاه: `id term pos level ipa rank diff fa def ex col syn ant note emoji topics forms mnemonic premium image` |
| `packs.json` | `{packs:[{id,title,desc,emoji,words,level,seed,premium}]}` |
| `manifest.json` | نسخه، شمار واژه‌ها به تفکیک سطح، شمار دیالوگ‌ها، شمار بسته‌ها و توزیع نقش دستوری |

شناسه‌ها `{level}{3 رقم}` هستند (مثلاً `b1_042`) و در همه‌ی فایل‌ها یکتا می‌مانند.

## تصاویر واژه‌ها (`assets/images/`)

تصویر هر واژه **بخشی از فایل متنی نیست**؛ بیلدر هنگام ساخت بسته، پوشه‌ی
`assets/images/` را نگاه می‌کند و اگر فایلی هم‌نام شناسه‌ی واژه باشد، ارجاع آن
را در `image` همان واژه می‌گذارد:

```
assets/images/b1_042.webp  →  "image": "assets/images/b1_042.webp"
```

- پسوندهای پذیرفته‌شده: `.webp` (پیشنهادشده)، `.png`، `.jpg`، `.jpeg`.
- اندازه‌ی پیشنهادی: کمتر از ۲۰۰ کیلوبایت، نسبت ۴:۳ یا ۱۶:۹.
- تصویر بزرگ‌تر از ۲ مگابایت هنگام ساخت هشدار می‌دهد.
- نبودن تصویر خطا نیست؛ رابط کاربری در آن حالت کارت تزئینی با حرف نخست
  واژه نشان می‌دهد. تصاویر آنلاین (فاز بک‌اند) از کلید `image_url` می‌آیند و
  اولویت پایین‌تری از تصویر محلی دارند.

## کارهایی که بیلدر خودکار انجام می‌دهد

- **تلفظ IPA:** تبدیل خروجی ARPAbet فرهنگ `cmudict` به الفبای آوانگاری بین‌المللی.
- **رتبه‌ی کاربرد:** محاسبه از پیکره‌ی `wordfreq` (۵۰٬۰۰۰ واژه‌ی اول) برای
  مرتب‌سازی هوشمند صف یادگیری.
- **درجه‌ی دشواری (۱..۵):** از سطح CEFR، رتبه‌ی کاربرد و املای واژه.
  (`a1/a2 → ۱`، `b1 → ۲`، `b2 → ۳`، `c1 → ۴`، `c2 → ۵` با اصلاح‌های جزئی)
- **الگوهای صرفی:** `term_forms()` شکل‌های منظم و بی‌قاعده‌ی واژه را می‌سازد تا
  در مثال‌ها و تمرین «جای خالی» درست تشخیص داده شود.
- **تصاویر:** ارجاع خودکار تصویر از پوشه‌ی `assets/images/` (بر پایه‌ی شناسه‌ی واژه).
- **اعتبارسنجی:** یکتا بودن شناسه، کد نقش دستوری/سطح، وجود خودِ واژه در مثال‌ها،
  هم‌خوانی واژه‌های بسته‌ها با واژگان، و رد شدن اعداد/کاراکترهای بیگانه.

## اجرا

```bash
python3 tools/build_content.py        # فقط پایتون استاندارد + cmudict/wordfreq اختیاری
```

اگر `cmudict` یا `wordfreq` نصب نباشند، بیلدر باز هم کار می‌کند: `ipa` خالی
می‌ماند و رتبه‌ها صفر می‌شوند (اپ هر دو حالت را تحمل می‌کند).

خروجی نمونه:

```
  words_a1.txt → 117 واژه
  …
  ✓ words_b1.json — 192 واژه (…KB)
  ✓ packs.json — 23 بسته
  ✓ manifest.json
```

## افزودن واژه‌ی تازه (دستور کار)

1. واژه را به فایل سطح مناسب اضافه کنید (خط تازه در `words_<level>.txt`).
2. اگر لازم است، در `media_lines.txt` دیالوگ و در `packs.txt` بسته‌ی مرتبط
   را به‌روز کنید.
3. `python3 tools/build_content.py` را اجرا کنید و هشدارها را بررسی کنید.
4. `node tools/dev/dartcheck.mjs .` و `flutter test` را اجرا کنید؛ تست‌های
   `test/data/content_source_test.dart` کیفیت محتوا (معنی فارسی، ترجمه‌ی مثال‌ها،
   اعتبار بسته‌ها) را می‌سنجند.

> نسخه‌ی محتوای تولیدشده در `manifest.json` ثبت می‌شود؛ افزایش آن به‌معنی
> بسته‌ی تازه برای کاربر است. به‌روزرسانی نهایی روی دستگاه از مسیر
> `ContentSource` (کلید `content_override_v1`) انجام می‌شود.
