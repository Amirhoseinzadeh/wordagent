# تست و کنترل کیفیت

## اجرا

```bash
flutter test                      # همه‌ی تست‌ها
flutter test test/domain          # فقط موتورهای دامنه
flutter test test/utils/fa_format_test.dart
flutter analyze
```

از آن‌جا که همه‌ی موتورهای آموزشی **تابع خالص** هستند و زمان از `AppClock`
(و در تست‌ها از یک ساعت ثابت) عبور می‌کند، هیچ تستی به شبکه، پلتفرم یا
ساعت واقعی وابسته نیست.

## یکپارچگی مداوم (CI)

گردش‌کار `.github/workflows/ci.yml` روی هر push و Pull Request این زنجیره را
اجرا می‌کند: `flutter pub get` → `flutter analyze` → `flutter test` →
`flutter build web --release`. مرحله‌ی آخر مهم است: تضمین می‌کند همه‌ی لایه‌ها
روی یک پلتفرم واقعی (وب) هم کامپایل می‌شوند.

## تحلیل ایستای سبک (بدون SDK)

در محیط‌هایی که Flutter نصب نیست، از اسکریپت `tools/dev/dartcheck.mjs` استفاده
کنید؛ این ابزار با tree-sitter فایل‌های Dart را می‌خواند و خطاهای پرتکرار را
می‌گیرد:

```bash
node tools/dev/dartcheck.mjs .
```

چه چیزهایی را می‌گیرد:

- خطای نحو و توازن بلوک‌ها،
- اعلان‌های تکراری در یک کتابخانه،
- نبود ایمپورت برای نوع‌های داخلی پروژه،
- آرگومان‌های نام‌دار نادرست/گمشده در سازنده‌ها،
- کلید ناشناخته در `S.*` و عضو ناشناخته در enum‌ها.

> این اسکریپت جای `flutter analyze` را نمی‌گیرد؛ فقط شبکه‌ی ایمنی سریع است.

## نکته‌های تست‌نویسی در این پروژه

- **زمان:** هرگز `DateTime.now()` در تست‌ها استفاده نمی‌شود؛ همه‌جا `testNow`
  یا `AppClock(provider: …)` تزریق می‌شود.
- **محتوا:** تست محتوا فایل‌های واقعی `assets/content` را (با mock کردن باندل
  دارایی‌ها) می‌خواند؛ بنابراین اگر واژه‌ای معنی فارسی نداشته باشد، تست می‌شکند.
- **بدون شبکه:** سرویس صوتی در تست‌ها با `FakeAudioService` جایگزین می‌شود و
  ذخیره‌سازی با `MemoryLocalStore` انجام می‌گیرد.
- **رفتار، نه پیاده‌سازی:** تست‌ها به جزئیات داخلی موتورها وابسته نیستند؛
  ورودی/خروجی و قوانین آموزشی سنجیده می‌شود.

## یافته‌های تست که به اصلاح کد انجامید

این‌ها نشان می‌دهد تست‌ها واقعاً کار می‌کنند و نه فقط پوشش صوری:

1. `WordRepositoryImpl` پس از به‌روزرسانی آنلاین، محتوای تازه را اعمال
   **نمی‌کرد** (نسخه‌ی بسته دوباره بار می‌شد) → حالا نسخه‌ی محلی اولویت دارد.
2. لرزش تصادفی بازه‌ی مرور **بعد از** محدودسازی اعمال می‌شد و می‌توانست
   فاصله را از سقف یک‌ساله عبور دهد → ترتیب اصلاح شد.
3. `FaFormat.compactNumber` برای اعداد گرد اعشار بی‌معنی می‌داد
   (`۱۲٫۰ هزار`) → اعداد گرد بدون اعشار نمایش داده می‌شوند.
4. `TextNormalizer.stripEndPunctuation` نشانه‌ی پرسشی فارسی «؟» را پاک
   نمی‌کرد → پشتیبانی از «؟» و «…» اضافه شد.
